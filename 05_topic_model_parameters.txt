TOPIC MODEL SPECIFICATION

Embedding model
---------------
Sentence-BERT: all-MiniLM-L6-v2

Document preprocessing
----------------------
Input documents consist of article abstracts retrieved from Scopus.
Documents with missing or empty abstracts were excluded.
No topic reduction or topic merging was applied after model estimation.

Embedding generation
--------------------
Embeddings were generated using Sentence-BERT (all-MiniLM-L6-v2).
The model's default maximum sequence length was used (256 word pieces).
Abstracts exceeding this limit were automatically truncated by the tokenizer.

Dimensionality reduction (UMAP)
-------------------------------
n_neighbors = 20
n_components = 5
min_dist = 0.0
metric = cosine
random_state = 42

Clustering (HDBSCAN)
--------------------
min_cluster_size = 25
min_samples = 10
metric = euclidean
cluster_selection_method = eom
prediction_data = True

Vectorization (c-TF-IDF)
------------------------
stop_words = english
min_df = 5
ngram_range = (1, 2)

BERTopic settings
-----------------
calculate_probabilities = True

Topic labeling
--------------
Topics were inspected manually using the highest-ranking c-TF-IDF terms and representative documents generated by BERTopic.
Canonical topic labels were assigned by the authors based on the substantive content of each topic.

Outputs provided
----------------
- Complete inventory of the 226 retained non-outlier topics
- Canonical topic IDs
- Topic labels
- Representative keywords
- Topic sizes
- Cross-table topic mappings
